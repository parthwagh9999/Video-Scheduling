                                    🩺 Auto-Healer, Self-Recovery & Unattended Study Mode
                                

                                Zero-Intervention System
                            

                            

                                

                                    Designed for your unattended daily routine: Click "Start Automation" in the morning, leave your PC scheduling, and go study without worrying. When issues arrive, the system automatically resolves transient errors in real time. If an issue requires human attention (like 2FA), it alerts you with a plain-English explanation and 1-click action buttons.
                                


                                

                                    

                                        
1. In-Flight Transient Auto-Heal

                                        

                                            If a YouTube modal scrim blocks pointer clicks, a dialog appears, or network times out, the engine clears the scrim (Escape key), waits 10s to stabilize, and retries up to 3 times automatically without failing the video.
                                        

                                    

                                    

                                        
2. 1-Click System Healer

                                        

                                            Click "⚡ Run Auto-Heal & Fix All" to clear orphaned Chrome SingletonLock files from abrupt crashes, recover stuck uploading jobs back to pending, and check SQLite database integrity.
                                        

                                        
                                    

                                    

                                        
3. Unresolved Issue Radar

                                        

                                            If an issue cannot be auto-resolved (e.g. 2FA verification challenge or account limit), it explains why in plain English and offers 1-click solutions: [↺ Re-arm & Retry], [📅 Shift Tomorrow], or [🔓 Log In Now].
                                        

                                    

                                


                                

                                    
💡 Recommended Morning Study Routine

                                    
    
                                        
  1. Navigate to 🩺 Auto-Healer & Issues in the sidebar.
    2. 
                                        
  2. Click "🎓 Check Study Readiness" to verify 100% pre-flight green status across network, browser cookies, quotas, and database.
    3. 
                                        
  3. Go to 📤 Publishing Queue and click "⚡ Start Live Uploading".
    4. 
                                        
  4. Go to study! The watchdog and auto-healer keep processing safely.
    5. 
                                    

                                

                            

                        

                    


                    
                    

                        

                            

                                

                                    🎬 Video Ingestion, 0.0s Thumbnails & Outro Concatenation
                                

                                FFmpeg Core
                            

                            

                                

                                    The video engine uses high-performance FFmpeg filter graphs to concatenate vertical MP4 clips with outro calls-to-action and extract crisp opening frame thumbnails.
                                


                                

                                    

                                        
🔄 Outro Alternating Rules

                                        
    
                                            
  • Every Second (Default): Video 0 has outro, Video 1 has no outro, Video 2 has outro...
    • 
                                            
  • Every Video: Appends the outro video to all 100% of discovered videos.
    • 
                                            
  • None: Bypasses concatenation; uploads original start videos directly.
    • 
                                            
  • Manual Selection: Provides an interactive checklist in Settings allowing custom selection per video with a live preview sequence table.
    • 
                                        

                                    

                                    

                                        
🖼️ 0.0s Opening Frame Thumbnails

                                        

                                            Shorts and Reels perform highest when the opening hook frame is cleanly presented as the cover. The engine extracts the exact opening frame (t=0.0s) as high-res JPEG into output/thumbnails/.

                                    🛠️ Frequently Asked Questions & Instant Recovery
                                

                                Troubleshooting
                            

                            

                                

                                    

                                        Q: What should I do if port 8899 or 8000 shows "Port already in use"?
                                        ▶
                                    

                                    

                                        The application launcher (launch_gui.py) automatically detects and terminates orphaned background instances holding port 8899. If needed manually on Windows PowerShell:
                                        

                                            netstat -ano | findstr :8899
taskkill /F /PID <PID>
                                            
                                        

                                    

                                


                                

                                    

                                        Q: How do I re-publish a video if I deleted the scheduled draft on YouTube Studio?
                                        ▶
                                    

                                    

                                        Go to the 📅 Publishing Calendar or 📤 Publishing Queue, click the video row to open the Reschedule Modal, and click the orange button:
                                        
↺ Mark Draft Deleted & Set Pending

                                        This resets the database record and enables the upload engine to schedule it again on the next queue run.
                                    

                                


                                

                                    

                                        Q: How does the YouTube Studio date-picker and time dropdown work?
                                        ▶
                                    

                                    

                                        YouTube Studio's schedule picker uses internal custom Web Components. The automation engine clicks the date trigger, clears text using keyboard backspaces, types the exact date, presses Tab/Escape to dismiss the date dropdown, and selects the matching time slot from the autocomplete list.
                                    

                                


                                

                                    

                                        Q: Where are Excel backups saved?
                                        ▶
                                    

                                    

                                        Every time you click "Sync Workbook" or make changes, an automated timestamped backup is saved in backups/ (e.g. Excel_backup_before_sync_20261021_143000.xlsx). Your original metadata is never at risk.
                                    

                                

                            

                        

                    


                    
                    

                        

                            

                                

                                    ⌨️ Command-Line Interface (CLI) Quick Reference
                                

                                Terminal Cheat Sheet
                            

                            

                                

                                    For headless background scripts, scheduled cron jobs, or power users, all features can be controlled from terminal:
                                


                                

                                    # 1. Launch the interactive Web GUI
python launch_gui.py

# 2. Discover raw video files in start video/
python run.py scan

# 3. Synchronize Excel metadata workbook with automatic backup
python run.py sync

# 4. Process videos and concatenate outros
python run.py process --rule every_second

# 5. Generate optimal publication calendar queue
python run.py schedule

# 6. Run automated publishing (dry-run mode, 3 videos)
python run.py publish --limit 3 --dry-run

# 7. Live publish to YouTube Studio (3 videos, headed browser)
python run.py publish --platform youtube --limit 3 --headed

# 8. Run unit test suite
pytest tests/ -v
